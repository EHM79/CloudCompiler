Architecture & Cloud Services

CloudCode runs on Vercel Serverless Functions with a Node.js (Express) backend and clean modern frontend.

  • Judge0 API: Executes code securely in isolated sandboxes.
  • Google Gemini API: Explains compilation and runtime errors with fixes.

Environment Variables Setup

To connect live Judge0 and Gemini keys, add them to your .env file or Vercel dashboard:

JUDGE0_API_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_API_KEY=your_rapidapi_key
GEMINI_API_KEY=your_gemini_api_key
